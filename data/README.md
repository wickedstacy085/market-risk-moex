# Данные

| Файл | Ряд | Источник |
|---|---|---|
| `imoex.csv` | Индекс МосБиржи (IMOEX), цена закрытия, с 08.01.2013 | Московская биржа, [ISS API](https://iss.moex.com/iss/reference/) |
| `ruonia.csv` | RUONIA, % годовых, с 09.01.2014 | Банк России, [динамика RUONIA](https://www.cbr.ru/hd_base/ruonia/dynamics/) |

Обновление: `python scripts/fetch_data.py` (на корпоративном ПК может понадобиться `pip install truststore`,
чтобы Python использовал сертификаты из хранилища ОС).

Особенность: торги акциями не проводились с 25.02 по 23.03.2022, поэтому доходность 24.03.2022 охватывает весь
разрыв.
