# Рыночный риск: VaR и ES по индексу Мосбиржи

**Страница проекта:** https://wickedstacy085.github.io/market-risk-moex

Скользящий однодневный VaR 99% и ES 97,5% по индексу IMOEX за 2014–2026 годы четырьмя методами и их бэктест;
ставка RUONIA как процесс Орнштейна–Уленбека (модель Васичека).

**Результаты.**
- Тесты Купика и Кристофферсена проходит только filtered historical simulation: 42 пробоя при ожидаемых 32.
  Историческая симуляция и нормальный VaR пробиваются почти вдвое чаще, и пробои идут кластерами.
- 24.02.2022 индекс упал на 33% — ни один метод не давал VaR больше 12%: VaR не заменяет стресс-тесты.
- Уровень, к которому возвращается RUONIA, — 6,4% в 2017–2021 и 17,3% в 2023–2026: модель OU с постоянным
  средним работает только внутри одного режима денежно-кредитной политики.

| Модуль | Что внутри |
|---|---|
| `src/risk/var.py` | историческая симуляция, нормальный, EWMA (λ = 0,94), FHS; VaR и ES; прогноз только по прошлым данным |
| `src/risk/backtest.py` | тест Купика (POF), тест независимости Кристофферсена, светофор Базеля |
| `src/risk/ou.py` | оценка OU через точную дискретизацию (AR(1)), симуляция |
| `tests/` | 22 теста: теория нормального VaR/ES, отсутствие look-ahead, эталонные серии пробоев, восстановление параметров OU |

Данные — [Московская биржа (ISS) и Банк России](data/README.md); обновление: `python scripts/fetch_data.py`.

```bash
pip install -r requirements.txt
pytest
quarto render
```
